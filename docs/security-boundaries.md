# 安全与责任边界

## 实施前提

建设单位及项目总体技术团队需按期提供合法、完整、可用的数据接口、接口文档、样例报文、点位数据、模型技术路线、计算参数、校验数据、预警规则和部署环境。上述条件延迟或重大变更造成的工作量与进度影响，应由项目各方书面确认。

污染扩散模型的技术路线、适用条件、参数体系、校验基准和精度要求由环境专业技术团队确认。软件开发负责算法的软件化实现、参数管理、任务调度、结果展示和版本追溯，不对超出模型适用范围或基础数据质量条件的结果作绝对准确性承诺。

## 客户端边界

- App 不直接连接生产数据库和监测设备。
- 监测数据、模型任务、预警处置、用户权限和操作日志通过服务端接口实现。
- 接口地址、账号、密钥、证书和签名文件不得进入源码仓库。
- 客户端只保存完成业务所需的最少数据，敏感缓存需加密并设置有效期。
- 生产环境禁用明文传输，日志不得记录令牌、身份证明或完整敏感参数。

## 源码与第三方组件

源码交付范围为项目自研代码、配置模板、构建脚本和测试。第三方地图、推送、数据库和其他 SDK 按各自许可协议使用，不包含第三方产品源代码。正式选型前需确认授权方式、离线能力、网络区域和持续服务成本。

## 手机通知

推送依赖建设单位提供可用账号、应用证书、网络条件和终端授权。服务端受理、推送服务接收、终端展示和用户确认分别留痕。终端离线、系统限制或用户关闭通知造成的未展示，不作为客户端程序缺陷判定依据。
